# iDad - Reparaturservice in Linz

Offizielles Repository für den Reparaturservice iDad von Iaroslav Komakha in Linz. Die Webpräsenz bietet Informationen zu Dienstleistungen, Kontaktdaten und Einblicke in den Werkstattalltag.

## Technologie und Struktur

Das Projekt basiert auf nativen Webtechnologien (HTML5, CSS3, Vanilla JavaScript).

| Ressource / Typ | Dateipfad / Details | Beschreibung |
| :--- | :--- | :--- |
| HTML-Struktur | `index.html` | Hauptseite mit allen Sektionen (Leistungen, Über uns, Bewertungen, FAQ, Kontakt) |
| Styling | `styles.css` | CSS-Design mit Variablen und Responsive Layouts |
| JavaScript | `script.js` | Logik für mobiles Menü, Formular, Modals sowie Cookie- und Google-Maps-Einbindung |
| Typografie | `fonts/` | Lokale Einbindung der Schriftart Montserrat |
| Medien (Bilder) | `img/` | WebP-Bilder (`1.webp` bis `4.webp`), Logos und Favicons (`favicon.svg`, `img/logo.ico`) |
| Medien (Video) | `res/` | Hero-Hintergrundvideo (`res/video_1.mp4`) inkl. Poster (`res/video_1_poster.jpg`) |
| vCard | `reparaturpartner.vcf` | Digitale Visitenkarte für Kontaktdaten |
| Rechtliches | `impressum.html`, `datenschutz.html` | Impressum und Datenschutzerklärung |
| Externe Dienste | Web3Forms & Google Maps | Formularversand und Karteneinbindung nach Einwilligung |

## Features

- Responsives Design für mobile und Desktop-Endgeräte
- DSGVO-konforme Einbindung externer Dienste nach Cookie-Einwilligung
- Kontaktformular via Web3Forms API
- Lokale Asset-Einbindung ohne externe CDN-Abhängigkeiten
